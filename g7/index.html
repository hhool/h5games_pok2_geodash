About

GeometryLite is a mobile-first hub for fast, browser-native Geometry Dash builds and similar rhythm platformers. Our site focuses on delivering low-latency, touch-friendly web versions that run smoothly on phones and desktops without requiring downloads or installation. Each featured game is embedded directly on the page so you can jump into gameplay instantly; we provide sensible controls (fullscreen, reset) and sandboxed embeds to keep sessions secure.
